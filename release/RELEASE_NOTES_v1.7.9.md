# PrintSphere v1.7.9

- Loading and unloading animations resume if a page transition is interrupted.
- The print progress ring keeps its last value when a cloud report resumes a paused job without a new progress value.
- Cloud printer profiles can discover the local address and access code when the printer reports them. Manually configured values take precedence.
- Improved nozzle temperature reporting, camera connections and Web Config reliability.

Use the firmware for your display. Upload the OTA image through Web Config to update an existing device and retain its settings. Use the factory image for a fresh installation. [PrintSphere Web Installer](https://cptkirki.github.io/PrintSphere/flash/)
